# 🌤️ Sky Manager

**Sky Manager**& is a modern, AI-powered web application designed to manage, visualize, and analyze data efficiently through an intuitive and responsive interface. It leverages real-time cloud services and intelligent insights to enhance user experience and decision-making.

Key Features
🔐 **Secure Authentication** using Firebase Authentication
☁️ **Real-time Database** with Firestore
📊 **Interactive Dashboard** with dynamic data visualization
🤖 **AI-Powered Insights** using Genkit + Google Gemini
⚡ **High Performance** with Next.js 15 (App Router)
🎨 **Modern UI/UX** with Tailwind CSS & ShadCN UI
📱 **Fully Responsive Design** for all devices

🧠 What Makes This Project Stand Out
* Integrated **AI-based data interpretation** for smarter insights
* Designed with **scalable architecture** using Next.js & Firebase
* Follows **modern full-stack best practices**
* Clean and maintainable **TypeScript-based codebase**

🛠️ Tech Stack
* **Language:** TypeScript
* **Frontend:** React 19, Next.js 15
* **Styling:** Tailwind CSS
* **UI Components:** ShadCN UI (Radix-based)
* **Backend:** Firebase

  * Authentication
  * Firestore Database
* **AI Integration:** Genkit + Google Gemini
* **Charts:** Recharts
* **Icons:** Lucide React

📁 Project Structure
src/

⚙️ Getting Started
1. Clone Repository
git clone https://github.com/your-username/sky-manager.git
cd sky-manager

2. Install Dependencies
npm install

3. Setup Environment Variables
Create a .env file:
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
GEMINI_API_KEY=

4. Run the App
npm run dev
Open: http://localhost:3000
